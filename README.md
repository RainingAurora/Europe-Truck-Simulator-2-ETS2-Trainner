# ETS2 驾驶辅助四项修改器

中文免安装窗口，支持《欧洲卡车模拟 2》**1.62.1.0 x64 单机版**。

支持以下功能：
1. 无限油量
2. 不会疲劳
3. 不会翻车（提供两种方式防止翻车，可同时开启）

适配的游戏文件通过 SHA-256 校验。支持的文件指纹见 [测试记录](TEST_RESULTS.md)。

## 使用

1. 从 GitHub Releases 下载 Windows 运行包并解压。校验值见包内的 `SHA256SUMS.txt`。
2. 启动游戏，进入单机存档的驾驶座。
3. 双击 `ETS2Trainer.exe`，等待显示“驾驶场景已连接”。
4. 按需开启下列四项功能，也可以使用快捷键。四个开关独立，“自然稳定辅助”和“强力主动扶正”允许同时开启。

| 操作 | 快捷键（主键盘数字） |
| --- | --- |
| 切换无限油量 | Ctrl + Alt + 1 |
| 切换不会疲劳 | Ctrl + Alt + 2 |
| 切换自然稳定辅助 | Ctrl + Alt + 3 |
| 切换强力主动扶正 | Ctrl + Alt + 4 |
| 全部关闭 | Ctrl + Alt + 0 |

无限油量启用后立即补满，并以目标 100 毫秒周期保持有效满油量。关闭后保留当前油量，恢复正常消耗。不会疲劳启用后将玩家的驾驶疲劳分钟数清零并保持为零；关闭后从当前状态自然累积。

自然稳定辅助在侧倾超过约 5°，或预测将超过该角度时，对车头和挂车施加反向滚转角速度，保留转向和正常坡度运动。它允许一定侧倾。

强力主动扶正监测车头及挂车。任一侧倾超过 35° 时，功能会调整两者和驾驶室的姿态，短暂抬升 0.3–0.8 米并清除车辆速度。两次介入至少间隔 2 秒。可同时开启两项辅助，让稳定辅助先抑制侧倾，强力扶正处理越过阈值的情况。

暂停、打开菜单和读档期间，已开启的功能会显示等待或挂起，重新进入有效驾驶场景后自动恢复。同一游戏进程内切换档案也会沿用开关状态。游戏进程退出后四个开关都会关闭，下次启动需要重新开启。关闭修改器即可停止全部修改，随后由游戏正常更新油量、疲劳和车辆状态。

窗口会显示车头/挂车的实时侧倾角及主动扶正次数。物理辅助显示“监测中”表示已启用并通过数据校验；“已主动扶正 N 次”是本次连接期间的实际介入次数。较小屏幕会自动提供滚动条。

无需安装 Cheat Engine、Python、额外游戏插件或驱动。运行环境为 Windows 64 位与 .NET Framework 4.8 或兼容版本。

## 状态与排查

- 等待游戏启动：启动 `eurotrucks2.exe`；只支持一个游戏进程。
- 游戏文件不匹配：当前程序仅接受已验证的游戏文件。版本号相同但文件不同也会拒绝写入，需要重新适配。
- 无法访问游戏：修改器和游戏应以相同权限运行。若游戏以管理员权限运行，修改器也需以管理员权限启动。
- 游戏暂停 / 菜单中：回到驾驶场景后自动恢复。
- 对象类型不匹配 / 数据异常：该功能停止写入，等待数据重新有效；可以先读档或重启游戏。影响车辆物理结构的 MOD 需要另行验证。
- 快捷键被占用：未注册的快捷键不可用，窗口按钮仍可正常操作。

日志在 `%LOCALAPPDATA%\ETS2Trainer\logs`，可通过窗口的“打开日志”访问。当前仅针对单机柴油卡车验证，不提供 Convoy、TruckersMP 或其他游戏版本的兼容承诺。

物理辅助已验证标准半挂组合，包括两项辅助同时开启的道路行驶，以及静止状态下 55° 和反向 90° 倾斜后的扶正。车辆接近竖直俯仰时会暂缓滚转修正。多节挂车、其他车辆结构或物理 MOD 尚未验收。验收细节见测试记录。

## 源码与构建

在项目目录的 PowerShell 中执行：

```powershell
.\build.ps1 -Test
```

使用 Windows 自带的 Framework64 C# 编译器；输出为 `dist\ETS2Trainer.exe`。构建过程同时生成诊断工具，并运行 `tests\TrainerTests.cs` 中的自动化检查。运行中的 EXE 可能被 Windows 锁定，重新构建前先关闭修改器及诊断工具。

`tools\bin\Diagnostics.exe 30 off` 只读观察 30 秒。参数 `fuel`、`fatigue`、`both` 分别测试油量、疲劳及二者；`natural`、`strong`、`stability` 测试两项辅助的独立/同时运行；`all` 同时开启四项。诊断工具退出时停止写入。

构建后运行 `./package.ps1` 可生成运行包和源码快照。详见 [测试记录](TEST_RESULTS.md) 和 [实现说明](IMPLEMENTATION.md)。
